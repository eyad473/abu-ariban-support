# موقع الدعم الفني — مخيم أبو عريبان (نسخة Cloudflare)

رابط منفصل تمامًا عن لوحة المناديب (`admin.html`) — العائلات ما بتشوف ولا بتوصل لأي بيانات إدارية سرية. نفس قاعدة البيانات (`abu-ariban-db`) مشتركة مع التطبيق الموحد، فبيانات العائلات (الأسماء، أرقام الهوية، أفراد الأسرة) تُقرأ من هناك مباشرة — ما في تكرار بيانات.

## ⚠️ ملاحظة مهمة — الفرق عن النسخة الأصلية (Railway)

هاي إعادة بناء لموقع الدعم الفني ليشتغل على Cloudflare (مجاني دائم). الأساسيات كلها موجودة ومطابقة للسلوك الأصلي:
- تحقق هوية بسؤال أمني ✅
- تقديم طلب (شكوى/ملاحظة/استفسار/مشكلة) يوصل لتلغرام فورًا ✅
- الرد بالـ Reply على رسالة الطلب بتلغرام يوصل تلقائيًا لصاحب الطلب ✅
- تفقد حالة طلب سابق بدون تسجيل دخول ✅
- حظر مؤقت بعد محاولات فاشلة متكررة ✅
- `/setgroup`, `/stats`, `/help` ✅

**مو موجود بعد** (كانت موجودة بالنسخة القديمة، ممكن نضيفها لاحقًا لو احتجتها):
- إشعارات Web Push المباشرة للجوال (قررنا نتجاوزها — مو ضرورية حسب كلامك)
- إرفاق ملفات/صور بالطلب
- أوامر البحث والتعديل المتقدمة بتلغرام (`/searchname`, `/editdata`, `/addperson`, `/removeperson`, `/fixid`) — بدلها صارت إدارة العائلات من لوحة المناديب (`admin.html`) بالتطبيق الموحد
- استيراد دفعات Excel عبر رفع ملف بتلغرام، وتصدير Excel (`/exportxlsx`) — الاستيراد الأولي هيصير مرة وحدة من ملفك الحالي، والإدارة بعدها من لوحة المناديب
- الإعلانات العامة (`/announce`) — الجدول موجود بقاعدة البيانات (`support_announcement`) بس بدون واجهة تحكم بعد

---

## 1) تنفيذ الجداول الإضافية على نفس القاعدة

من لوحة Cloudflare → D1 → `abu-ariban-db` → Console، نفّذ محتوى `schema-support.sql` (جدول-جدول متل ما عملنا بالمرة الأولى، تفاديًا لمشكلة اللصق الكبير).

## 2) إنشاء بوت تلغرام (أو استخدام بوت موجود)

1. افتح تلغرام، دردش مع **@BotFather**
2. `/newbot` → اتبع التعليمات → بياخدك رمز (Token) شكله `123456:ABC-DEF...`
3. احتفظ فيه، رح تحتاجه بالخطوة الجاية

## 3) معرفة الـ Chat ID الشخصي تبعك

1. دردش مع **@userinfobot** بتلغرام
2. هيرسلك رقم شات شكله `123456789` — هذا هو `TELEGRAM_OWNER_CHAT_ID`

## 4) رفع المشروع ونشره (نفس أسلوب المرة الأولى)

1. ارفع مجلد `abu-ariban-support` كامل (public, worker, wrangler.toml, schema-support.sql) لمستودع GitHub جديد اسمه مثلاً `abu-ariban-support`
2. Cloudflare Dashboard → Workers & Pages → Create → Workers → **Connect to Git** → اختار المستودع → Save and Deploy
3. فعّل رابط workers.dev من تبويب **Domains** (نفس الخطوة يلي عملناها بالتطبيق الأول)

## 5) ضبط المتغيرات السرية

من صفحة الـ Worker الجديد (`abu-ariban-support`) → Settings → **Variables and Secrets** → Add variable:

| الاسم | القيمة | النوع |
|---|---|---|
| `TELEGRAM_TOKEN` | التوكن من BotFather | **Secret** |
| `TELEGRAM_OWNER_CHAT_ID` | رقمك الشخصي من userinfobot | Secret أو Text |

## 6) ربط الـ webhook (مرة وحدة فقط)

افتح هالرابط بالمتصفح (بدّل القيم بين `< >`):

```
https://api.telegram.org/bot<TELEGRAM_TOKEN>/setWebhook?url=https://<رابط-موقع-الدعم>/telegram-webhook
```

لازم يطلعلك رد فيه `"ok":true`.

## 7) تحديد مجموعة الإدارة

1. اعمل مجموعة تلغرام جديدة، ضيف البوت فيها كعضو
2. اكتب **`/setgroup`** من داخل المجموعة نفسها

## 8) رابط الموقع

`https://<رابط-موقع-الدعم>` — هذا هو الرابط يلي تشاركه مع العائلات (منفصل عن رابط لوحة المناديب).
